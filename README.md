<h1>TrendWave - FULL STACK E-COMMERCE WEBSITE</h1>
<p>A fully functional eCommerce web application built with the MERN stack (MongoDB, Express.js, React.js, Node.js). Users can browse products, add them to cart, make secure payments, and place orders. Admins can manage products, categories, and orders from the dashboard.</p>

  <h2>🚀 Features</h2>
    <h3>🛍️ User Features</h3>
     <h3>🛍️ User Features</h3>
  <ul>
    <li>Browse products by category</li>
    <li>Product size selection</li>
    <li>View product details and similar products</li>
    <li>Add to cart and checkout</li>
    <li>Cash on Delivery & Braintree payment gateway</li>
    <li>View and manage orders</li>
    <li>User authentication (register/login)</li>
  </ul>

  <h3>🛠️ Admin Features</h3>
  <ul>
    <li>Admin authentication</li>
    <li>Add/edit/delete categories and products</li>
    <li>Manage all customer orders</li>
    <li>View payments and order statuses</li>
  </ul>

  <h2>🧰 Tech Stack</h2>
  <ul>
    <li><strong>Frontend:</strong> React.js, React Router, Bootstrap/CSS Modules</li>
    <li><strong>Backend:</strong> Node.js, Express.js, MongoDB, Mongoose</li>
    <li><strong>Other:</strong> JWT, Braintree, Cloudinary, Render</li>
  </ul>
